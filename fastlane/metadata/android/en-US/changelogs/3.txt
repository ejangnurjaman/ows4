Version 1.0.1 update of OWS4:
- Added Select Method feature (Default Toolkit vs Custom with horizontal radio buttons).
- Default Toolkit supports multiple verified ZIPs (ows4.rawgame4.v1.zip, ows4.rawgame4.v2.zip, ows4.raw13g.v1.zip) with SHA-256 verification.
- Custom method supports selecting any folder via Storage Access Framework (SAF) folder picker with zero dangerous permissions.
- Improved UI, documentation, and stability.
